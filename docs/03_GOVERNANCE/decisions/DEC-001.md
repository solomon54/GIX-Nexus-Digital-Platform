# DEC-001: Technology Stack — Phase 1

- **Date:** 2026-08-17
- **Authority:** Project Owner (stakeholder decision)
- **Resolves:** OQ-framework, OQ-CMS-approach, OQ-109 (partial)
- **Decision statement:** The Phase 1 platform is built on Next.js 15 (App Router), TypeScript, Tailwind CSS v4, PostgreSQL, and Payload CMS v3 as the content management layer.
- **Rationale:** Next.js App Router satisfies the SSR/SSG requirement (locked in Ch.29). Payload CMS v3 runs natively on Next.js, uses PostgreSQL, and enforces a content lifecycle (Draft → Review → Published) that directly maps to the spec's governed workflow. TypeScript enforces the provenance and type-safety requirements. Tailwind enables the design-system token structure required by Ch.11.
- **Affected chapters:** Ch.15, Ch.18, Ch.22, Ch.23, Ch.29, Ch.31, Ch.35
- **Constraints carried forward:**
  - No GraphQL (REST only, per locked governance principle §D.11 and OQ-117 resolution via this decision)
  - PostgreSQL is the sole database (no MongoDB, Redis, etc. in Phase 1)
  - Payload CMS admin UI is the ONLY authenticated area — the public site remains fully anonymous
  - All content starts as Draft; no content ships to production without the governed lifecycle
