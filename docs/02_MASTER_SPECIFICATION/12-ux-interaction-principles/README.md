## Purpose

How users interact with the platform: component behavior, motion principles,
responsive/adaptive layout, and the interaction design language.

## What belongs here

- Component system and UI patterns
- Motion and interaction principles (animation, transitions, micro-interactions)
- Responsive design strategy and breakpoints
- Adaptive layout for low-bandwidth and constrained-device contexts (relevant for Ethiopia)
- Interaction states (hover, focus, active, disabled)
- Touch target requirements (44×44pt minimum — referenced from Ch.13)

(forms are blocked in Phase 1).
