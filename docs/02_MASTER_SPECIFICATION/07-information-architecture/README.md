## Purpose

The site's content structure: pages, navigation hierarchy, content types, and how
information is organized for public visitors in both locales.

## What belongs here

- Site map / page inventory
- Navigation structure (primary, secondary, footer)
- Content type definitions (e.g., Service Page, Sector Card, HSEQ Display,
  Future Objectives listing, Contact)
- URL structure
- Bilingual routing model (how EN and AM pages relate)

## Firm constraints that govern this chapter

- Navigation must reflect exactly 6 service groupings — no 7th item
- "Sectors We Serve" page exists; it is NEVER labeled "Clients" or "Our Clients"
- Future Objectives page exists as a separate section, never merged with Services
- No pages for: login, client portal, vendor registration, RFQ, fault reporting
