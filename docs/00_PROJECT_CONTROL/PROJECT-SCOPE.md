# Project Scope (Phase 1)

## In scope
- Public bilingual website: company identity, 6 service groupings, HSEQ policy,
  personnel/equipment categories, 14 target sectors, future objectives, static contact info.
- Lightweight CMS with a governed content lifecycle (Draft → Review → Approval → Published).
- Accessibility (WCAG-aligned targets, 400% zoom, 44×44pt touch targets).
- Localization: en-US and am-ET, Western digits, Africa/Addis_Ababa timezone,
  Gregorian + Ethiopian calendar display.

## Explicitly out of scope for Phase 1
- Authentication of any kind (no login, no client accounts).
- CRM / ERP / HRIS / project-management / field-service systems.
- Contact/inquiry forms with real submission handling (static contact info only
  until this is explicitly approved — see open questions in 03_GOVERNANCE/open-questions/).
- Fault reporting, RFQ workflow, vendor registration workflow.
- AI-assisted search or semantic retrieval.
- Client portal.
